# Budget Planner — Theme Preserved React Wrapper

This project keeps the original Budget Planner HTML, CSS, JavaScript, page layouts, colors, fonts, and interactions unchanged under `public/legacy/`. A small React + Vite app shell mounts the original application so the React project starts correctly without redesigning the interface.

## Run
1. Extract the ZIP.
2. Open the folder containing `package.json` in CMD.
3. Run `npm install`
4. Run `npm run dev`
5. Open the Local URL printed by Vite.

The original app remains in `public/legacy/`. This is a React/Vite wrapper, not a full rewrite of every legacy screen into React components. Original data/auth behavior and browser storage remain as in the supplied project.
